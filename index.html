2

3
Analyze

Review maturity scores across all requirements. Identify patterns and priority areas. Calculate overall maturity score.

Scoring Guide

General Scoring Principles

  1. Evidence-Based: Ratings must be supported by documented evidence
  2. Consistent: Use same criteria across all assessments
  3. Honest: Rate actual state, not aspirational state
  4. Defensible: Be prepared to justify ratings to auditors

Level-Specific Criteria

0 Non-existent:
  • No awareness of the requirement
  • No processes or controls implemented
  • No documentation exists
  • No plans to address
1 Initial:
  • Basic awareness of the requirement
  • Ad-hoc or informal implementation
  • Minimal or no documentation
  • Reactive approach
  • Success depends on individual efforts
2 Managed:
  • Basic processes exist
  • Some documentation available
  • Processes are repeatable
  • Basic measurements in place
  • Some training provided
3 Defined:
  • Formal, documented processes
  • Standardized across organization
  • Proactive approach
  • Performance measured
  • Continuous improvement activities
  • Full training coverage
4 Optimized:
  • Best practices implemented
  • Processes automated where possible
  • Continuous monitoring
  • Benchmarking against industry
  • Innovation and optimization
  • Culture of security excellence
